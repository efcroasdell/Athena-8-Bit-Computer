# Clock Module Oscilloscope Evidence

Store original oscilloscope captures for the Athena clock module in this directory.

Use filenames that identify the device, pin or node, state and date where practical. Examples:

- `556-pin01-discharge1-2026-09-13.jpg`
- `556-pin08-trigger2-idle-2026-09-13.jpg`
- `556-pin08-trigger2-pressed-2026-09-13.jpg`
- `556-pin09-output2-idle-2026-09-13.jpg`
- `556-pin09-output2-triggered-2026-09-13.jpg`

The written measurement record belongs in `docs/measurements/clock-556-verification.md` and should link to the original evidence files stored here.

Do not alter an original capture merely to make it agree with an expected result. If annotated or cropped versions are useful, retain the original and store the derivative with a clearly different filename.
