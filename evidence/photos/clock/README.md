# Clock Module Photographic Evidence

Store photographs of the Athena clock-module breadboard and component wiring in this directory.

Photographs are engineering evidence. Each image should be treated as a record of the circuit at that moment rather than as an illustration of what the circuit was expected to be.

Use filenames that identify the subject and date where practical, for example:

- `clock-overview-2026-09-13.jpg`
- `556-step-switch-wiring-2026-09-13.jpg`
- `556-timer2-timing-network-2026-09-13.jpg`
- `sn7400-run-manual-latch-2026-09-13.jpg`
- `sn74ls157-clock-selector-2026-09-13.jpg`

Where a photograph is used to support a wiring or fault conclusion, reference its filename from the corresponding Markdown record.

Project rule: **every photograph is fresh evidence**. Trace only connections that are actually visible. Do not infer a missing connection from the expected schematic or from an earlier photograph.
